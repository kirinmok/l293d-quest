# L293D 闖關

給國中生的 L293D 馬達驅動模組接線練習，開瀏覽器就能玩，不用安裝。

| 關卡 | 檔案 | 內容 |
|---|---|---|
| L1 | `L1.html` | 讓馬達轉起來 |
| L3 · A | `L3-A.html` | L293D 模組 1:1 寫實、點腳位發亮 |
| L3 · B | `L3-B.html` | L293D ＋ Arduino Nano 外觀對照 |
| L3 · C | `L3-C.html` | Nano 插麵包板、L293D 寫實連連看 |

首頁是 `index.html`。開 GitHub Pages 之後，學生用網址就能打開。
